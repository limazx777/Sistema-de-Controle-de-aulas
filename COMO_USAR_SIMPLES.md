# 🚀 Como Usar o Sistema (SEM SERVIDOR)

## ✅ **SISTEMA FUNCIONANDO 100% OFFLINE!**

### 🎯 **Como Iniciar:**

1. **Abra o arquivo `public/index.html` no navegador:**
   - Clique duas vezes no arquivo
   - Ou arraste para o navegador
   - Ou clique com botão direito > "Abrir com" > Navegador

2. **Pronto! O sistema está funcionando!**

---

## 💾 **Como os Dados São Salvos:**

### ✅ **Salvamento Automático:**
- Todos os dados são salvos automaticamente no navegador
- Não precisa fazer nada, salva sozinho!
- Funciona mesmo fechando e abrindo o navegador

### 📥 **Backup dos Dados:**
1. Vá na aba **"Relatórios"**
2. Clique em **"📥 Baixar dados.json"**
3. Salve o arquivo em local seguro
4. Este arquivo contém TODOS os seus dados

### 📤 **Restaurar Dados:**
1. Vá na aba **"Relatórios"**
2. Clique em **"📤 Importar dados.json"**
3. Selecione o arquivo que você salvou
4. Confirme a importação

---

## 🎯 **Como Usar:**

### **1. Cadastros:**
- Cadastre turmas, professores, disciplinas e salas
- Use o formulário "Cadastrar Dados Completos" para adicionar tudo de uma vez

### **2. Aulas:**
- Vá na aba "Escala de Aulas"
- Preencha todos os campos
- Selecione as semanas do mês
- Clique em "Cadastrar Aula"

### **3. Relatórios:**
- Vá na aba "Relatórios"
- Gere relatórios Excel
- Exporte/Importe dados JSON

---

## ⚠️ **IMPORTANTE:**

### **Backup Regular:**
- Faça backup do `dados.json` regularmente
- Guarde em pen drive, nuvem, etc.

### **Não Limpar Navegador:**
- Não limpe os dados do navegador
- Ou faça backup antes de limpar

## 📞 **Se Algo Der Errado:**

1. **Dados sumiram?**
   - Importe o arquivo `dados.json` que você salvou

2. **Sistema não carrega?**
   - Recarregue a página (F5)
   - Ou feche e abra o navegador

3. **Erro na tela?**
   - Pressione F12 para ver detalhes
   - Recarregue a página
