# 🎨 Identidade Visual - ILEDE

## ✨ Nova Identidade Visual Implementada!

O sistema agora utiliza a **paleta de cores oficial da ILEDE** - Educação Sem Fronteiras!

---

## 🎨 Paleta de Cores

### Cores Principais

**Amarelo ILEDE** (#FFC107)
- Cor primária da marca
- Usada em: cabeçalho, botões, destaques

**Dourado ILEDE** (#FFA000)
- Cor secundária
- Usada em: gradientes, hover, títulos

**Cinza Escuro** (#333333)
- Cor de texto principal
- Usada em: textos sobre fundo amarelo

---

## 🖼️ Logo ILEDE

### Localização
- **Arquivo**: `public/logo-ilede.svg`
- **Posição**: Cabeçalho do sistema (canto superior)
- **Tamanho**: 120px de largura (responsivo)

### Características
- Logo em formato SVG (vetorial)
- Cor amarela (#FFC107)
- Sombra suave para destaque
- Responsiva e escalável

---

## 🎯 Aplicação das Cores

### 1. Cabeçalho
```
Fundo: Gradiente amarelo (#FFC107 → #FFA000)
Texto: Cinza escuro (#333)
Logo: Amarelo com sombra
```

### 2. Fundo da Página
```
Gradiente amarelo/dourado
Efeito degradê suave
```

### 3. Botões
```
Fundo: Gradiente amarelo (#FFC107 → #FFA000)
Texto: Cinza escuro (#333)
Hover: Dourado mais escuro
```

### 4. Abas (Tabs)
```
Aba ativa: Texto dourado (#FFA000)
Linha inferior: Amarelo (#FFC107)
Hover: Cinza claro
```

### 5. Cards e Títulos
```
Títulos H2: Dourado (#FFA000)
Bordas de aulas: Amarelo (#FFC107)
```

### 6. Inputs e Forms
```
Foco: Borda amarela (#FFC107)
Botões: Gradiente amarelo/dourado
```
