# 🚀 COMO USAR O WHATSAPP COM PDFs - GUIA RÁPIDO

## ⚡ Início Rápido

### 1️⃣ **Iniciar o Sistema**
```bash
node server.js
```
Acesse: `http://localhost:3000`

### 2️⃣ **Conectar WhatsApp**
1. Clique na aba **"📱 WhatsApp"**
2. Clique em **"🔗 Conectar WhatsApp"**
3. **Escaneie o QR Code** com seu celular
4. Aguarde aparecer **"Conectado"** ✅

### 3️⃣ **Enviar Relatório com PDF**
1. **Número**: Digite apenas números (ex: 11999999999)
2. **Aula**: Escolha uma aula da lista
3. Clique **"📤 Enviar Relatório com PDF"**

### 4️⃣ **Enviar Mensagem Personalizada**
1. **Número**: Digite apenas números
2. **Mensagem**: Digite sua mensagem
3. **PDF** (opcional): Escolha uma aula para anexar
4. Clique **"📤 Enviar Mensagem"**

## 🎯 Funcionalidades Principais

### ✅ **O que funciona:**
- ✅ Conexão via QR Code
- ✅ Envio de mensagens de texto
- ✅ Anexos PDF automáticos
- ✅ Relatórios detalhados das aulas
- ✅ Envio em lote (todas as aulas)
- ✅ Mensagens personalizadas
- ✅ Teste de conexão

### 📱 **Formato das Mensagens:**
```
📚 *RELATÓRIO DE AULA*

📝 *Nome da Aula*
🏫 Instituição
📅 Data
⏰ Horário
📚 Disciplina
👥 Turma
📊 Carga Horária

📎 *Anexo:* Relatório completo em PDF
```

### 📄 **PDFs Gerados:**
- **Layout profissional** com informações completas
- **Dados enriquecidos** (turma, professor, disciplina)
- **Limpeza automática** após envio
- **Formato A4** otimizado

## ⚠️ Importante Saber

### 🔒 **Limitações:**
- **Apenas números brasileiros** (código 55)
- **3 segundos** entre envios (evitar spam)
- **WhatsApp Web** deve estar ativo
- **Conexão única** por vez

### 🛠️ **Se der problema:**
1. **QR Code não aparece**: Aguarde e recarregue
2. **Conexão falha**: Verifique WhatsApp Web
3. **Mensagem não enviada**: Verifique o número
4. **PDF não anexado**: Verifique se selecionou a aula

### 🧪 **Testar primeiro:**
Use o botão **"🧪 Testar Conexão"** antes de enviar relatórios!
